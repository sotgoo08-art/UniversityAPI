# University API
Node.js + Express REST API (MongoDB, JWT, Swagger).

## Lokal ajilluulah
1. `npm ci`
2. `.env.example`-iig `.env` bolgon huulj utguudiig oruulna
3. `npm start` -> http://localhost:3000, Swagger: /api-docs

Swagger UI: /api-docs

## Auth endpoints
- POST /auth/register
- POST /auth/login
- GET /auth/me
